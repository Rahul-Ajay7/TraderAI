# Crypto & Stock Prediction Platform

## Features
- Real-time price data from CoinGecko (crypto) and Alpha Vantage (stocks)
- AI-powered price predictions
- Clear BUY/SELL/HOLD signals
- Portfolio tracking with profit/loss
- Risk assessment

## API Keys Needed
Get free API keys:
- **CoinGecko**: https://www.coingecko.com/api (no key required for basic)
- **Alpha Vantage**: https://www.alphavantage.co/support#api-key (free)

## Setup
1. Get API keys
2. Add to .env file
3. Run `npm install && npm run dev`

## Tech Stack
- React + Vite
- Tailwind CSS
- Recharts for visualization
- CoinGecko API (free)
- Alpha Vantage API (free tier)
